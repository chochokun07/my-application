# リンバスバトルデータ

人格の評点・評価コメント・変更履歴を、人格ごとのJSONファイルで管理する小さなWebアプリです。E.G.O用ディレクトリは将来の拡張用です。

## 起動

Node.js 20以上を用意し、`.env.example` を参考に環境変数 `ADMIN_PASSWORD`、`VIEWER_PASSWORD`、`SESSION_SECRET` を設定して `npm start`。ブラウザで `http://localhost:3000` を開きます。依存パッケージのインストールは不要です。`npm test` で認証・保存・履歴のHTTPテストを実行できます。

公開先のサーバーには書き込み可能な永続ディスクが必要です。`DATA_DIR` にそのディスク上のディレクトリを指定してください。既定はこのリポジトリの `data/` です。評点は `data/identities/<ID>.json` に保存されます。制作中は閲覧にもパスワードが必要です。後に `PUBLIC_READ=true` を設定すると閲覧だけを公開できます。編集は引き続き管理者パスワードが必要です。

パスワードとセッション秘密鍵はGitにコミットしないでください。Gitで評点JSONの変更履歴も管理したい場合は、運用時のデータディレクトリを別途バックアップ・コミットする必要があります。サイト上の評点変更履歴はJSON自身に記録されます。
