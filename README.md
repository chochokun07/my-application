# My application v1.0.4

個人の活動を一か所で管理するための、静的PWAアプリケーションです。  
To Doを中心に、研究・趣味の活動、作業時間、ローカル研究サーバーをまとめて扱えます。

## 主な機能

### To Do管理

- タスクの追加・編集・削除
- 完了・未完了の切り替え
- 状態、期限、優先度、メモの管理
- 今日・すべて・完了の表示切り替え
- タスク検索
- タグ候補からのタグ選択
- ページ名と同じタグによる活動ページへの自動振り分け
- メインTo Doと各活動ページでのタスク共通管理

### 共通ノート

- メインのノート一覧から全ノートを表示
- 研究・趣味・創作など活動ページごとのノート表示
- 活動ページとメイン一覧から同じノートを開いて編集・削除
- ノートのタイトル・本文・所属活動の管理
- ノート検索と活動別フィルター

### 作業時間記録

作業時間を合計値ではなく、操作イベントとして時刻付きで保存します。

- 作業開始
- 休憩開始
- 作業再開
- 作業終了
- 未作業・作業中・休憩中の状態表示
- 作業中・休憩中の経過時間表示
- 終了忘れや長時間作業の警告
- 終了時刻の修正、継続確認
- 日単位の作業イベント管理
- 作業開始時のタスク選択
- ジャンルとセッション用メモの保存
- 作業記録画面でのタスク・ジャンル・メモ確認
- LOGの日付クリックによる作業セッションの編集オーバービュー
- 作業中のタスク・ジャンル・メモ編集
- 週のジャンル別作業時間集計
- 作業記録の週次カレンダー表示とイベント監査
- 日作業時間・週作業時間の表示
- 作業記録の再読込

### 活動ページ

- 研究ページ
  - 研究予定の管理
  - 研究プランの管理
  - 研究タスクの進捗表示
  - 現在の研究状態と最近の研究記録の確認
  - 予定を時間軸で表示
- 趣味ページ
  - 動画プロジェクトの管理
  - プロジェクトの並べ替え
  - 構想ページ・台本ページ
  - チャプター、セリフ、話者の管理
  - 台本の書き出し
- 設定画面
  - ページ名・表示文言の変更
  - 活動項目の追加・削除
  - タグ候補の追加・削除

### 研究サーバー・Research Packet連携

自宅PCで起動した研究サーバーと接続し、研究資料や研究状態を確認できます。

- 研究サーバーの接続状態確認
- 現在の研究状態と最近の記録の表示
- 研究ファイル一覧と本文プレビュー
- ローカル資料からのResearch Packet生成
- Packet作成中のLoading表示と経過時間表示
- 選択資料を含むPacketのコピー
- PacketをSolへ渡すための出力
- 人間が採用したSolの回答を研究記録へ反映

研究ファイル本文、接続URL、アクセストークンはSupabaseへ保存しません。研究サーバーの設定方法は [research-server/README.md](research-server/README.md) を参照してください。

## データ保存と同期

同期を使わない場合は、設定なしでこの端末のローカル保存を利用できます。

PC・スマートフォン間で同期する場合は、次の設定を行ってください。

1. Supabaseでプロジェクトを作成する。
2. SupabaseのSQL Editorで、最新の `supabase/schema.sql` を実行する。
3. SupabaseのProject Settings → APIから、Project URLとanon（またはpublishable）keyを確認する。
4. `config.js` の `SUPABASE_URL` と `SUPABASE_ANON_KEY` に入力する。
5. GitHub Pagesへ公開する。

Supabaseでは、主に次のデータをユーザー単位で管理します。

- タスク
- 研究プラン
- 研究予定
- 作業時間イベント（`work_events`）
- 共通ノート（`notes`）

Row Level Security（RLS）を使用しているため、データベース側でもユーザーごとのアクセスを制限します。  
`config.js` には公開用キーだけを設定し、`service_role` keyは絶対に入れないでください。

## GitHub Pagesでの公開

GitHub FreeでGitHub Pagesを使う場合、リポジトリは公開設定が必要です。

1. リポジトリへファイルをpushする。
2. GitHubのSettings → Pagesを開く。
3. 公開元を `main` ブランチのルートに設定する。

タスクや研究データはGitHubではなく、ローカルストレージまたはSupabaseに保存されます。

## ローカル確認

プロジェクトフォルダーで次を実行します。

```bash
python3 -m http.server 8080
```

その後、ブラウザで `http://localhost:8080` を開いてください。

### 作業記録の確認

作業記録画面では、`work_events`に保存された発生時刻付きイベントを読み込み、作業時間を日単位のタイムラインとして表示します。日付をクリックすると、セッションごとのタスク・ジャンル（タグ）・メモを確認・編集できます。イベント一覧には、作業開始・休憩開始・作業再開・作業終了、登録時刻の差分、イベント順序の異常を表示します。Supabaseを使う場合は「再読込」でデータベースから再取得できます。

SupabaseのSQL Editorでは、ログインユーザーの識別子を確認した上で、次のように保存内容を確認できます。

```sql
select id, event_type, occurred_at, created_at, activity_id, metadata
from public.work_events
where user_id = '<ユーザーID>'
order by occurred_at asc, created_at asc;
```
